# 🇯🇵 Project 03 - Travel Planner

A beginner-friendly Python console application that helps users create a simple travel plan for their dream trip.

This project was built as part of my **Python Automation Learning Journey** to practice Python fundamentals through a real-world inspired application.

---

## 🚀 Features

* 👤 Collect traveller information
* 🌏 Enter dream country
* 💰 Calculate and categorize travel budget
* 📍 Create a personalized travel wishlist
* 🔁 Store destinations using Python Lists
* 🔄 Display all wishlist places using a `for` loop
* 📊 Display total number of places selected
* 🖥️ Professional console-based interface

## ▶️ How to Run

1. Make sure Python 3 is installed.
2. Clone or download this repository.
3. Open the project folder.
4. Run the Python file:

```bash
python travel_planner.py
```
