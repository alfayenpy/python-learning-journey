# 🌍 Favourite Country Manager

A beginner-friendly Python mini project that allows users to enter their favorite countries and performs basic list and string operations.

## 🚀 Features

* Accepts 3 favorite countries as user input
* Stores countries in a Python list
* Displays all entered countries
* Shows the first country
* Shows the last country
* Checks whether Japan exists in the list
* Converts all country names to uppercase

## 🛠️ Concepts Used

* Variables
* User Input (`input()`)
* Lists
* List Indexing
* Membership Operator (`in`)
* String Methods (`upper()`)
* Output Formatting
