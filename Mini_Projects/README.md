# 🚀 Small Projects

This folder contains small Python projects that I build during my learning journey.

The goal is to apply the concepts I learn every week and improve my problem-solving skills through practice.

## 📌 Rules

* Build a small project after every 7 days of learning.
* Use only the concepts learned so far.
* Focus on understanding and implementation.
* Avoid copying complete solutions.
* Learn by building and experimenting.

## 🎯 Purpose

These projects are not professional portfolio projects.

They are practice projects created to:

* Strengthen Python fundamentals
* Improve logical thinking
* Develop problem-solving skills
* Track learning progress
* Build consistency
