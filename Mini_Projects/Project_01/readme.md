# 🎓 Student Information Card

## 📌 Description

Student Information Card is my first mini Python project created during my Python learning journey.

This project collects student details from the user and displays them in a clean and formatted information card. It was built using the concepts I learned during my first 7 days of Python practice.

---

## 🚀 Features

* Takes user input
* Displays a formatted student information card
* Calculates next year's age
* Uses string formatting for better output
* Cleans and formats user input using string methods

---

## 🛠 Concepts Used

* Variables
* Data Types
* User Input (`input()`)
* Type Casting (`int()`)
* Strings
* String Methods (`strip()`, `capitalize()`, `title()`)
* Escape Characters (`\n`)
* f-Strings
* Basic Arithmetic Operations
