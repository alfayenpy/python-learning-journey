# 🎓 Student Club Registration System

A simple Python mini project that simulates a **Student Club Registration System**.

This project allows students to register for different clubs, automatically removes duplicate club selections using **Python Sets**, and displays a clean registration summary.

---

## ✨ Features

- 👤 Student name input
- 🆔 Roll number input
- 📚 Club registration
- 🔄 Automatic duplicate removal using **Sets**
- 📋 Student details stored using **Tuples**
- 📝 Club selections stored using **Lists**
- 🔁 Uses loops for multiple club entries
- 📊 Displays registration summary
- 💬 Simple feedback using `if-else`

---
